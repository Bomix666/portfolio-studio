# Дизайн-система

Сайт — сам по себе главный кейс портфолио, поэтому система намеренно компактная и строгая.
Все токены ниже живут в `src/app/globals.css` (`@theme`); компоненты никогда не используют
«сырые» hex-значения.

## Направление

Тёмная, кинематографичная, редакционная эстетика. Почти чёрный фон, тёплый белый текст и один
сдержанный акцент — «янтарь лилии», взятый из ролика первого экрана. Крупный антиквенный
заголовочный шрифт на фоне спокойного гротеска и моноширинного. Стекло — только для *элементов
управления* (навигация, кнопки, поля, панели); контентные поверхности остаются плоскими и
резкими, чтобы стекло читалось как материал, а не декор.

## Цвет

| Токен | Значение | Применение |
| --- | --- | --- |
| `ink` | `#050505` | Фон страницы |
| `ink-2` | `#0b0b0c` | Приподнятые поверхности (форма, сцена образца) |
| `ink-3` | `#141415` | Вложенные поверхности, поля |
| `fg` | `#f4f3ef` | Основной текст (≈19:1 на ink) |
| `fg-muted` | `#a6a5a0` | Вторичный текст (≈8,4:1) |
| `fg-subtle` | `#7d7c78` | Только подписи и метаданные (≈4,8:1) |
| `line` / `line-strong` | белый 8 % / 16 % | Линии, разделители, контуры |
| `accent` | `#f2a33a` | Кольца фокуса, активные состояния, единичные акценты (≈10:1) |
| `accent-ink` | `#1a1105` | Текст на акценте |
| `danger` | `#ff7a6b` | Ошибки валидации (≈7,6:1) |
| `success` | `#8fe0b0` | Подтверждение успеха |

Правило: акцент появляется не больше одного раза на экран — как *сигнал* (активный пункт, фокус,
индикатор статуса).

## Типографика

| Роль | Шрифт | Примечания |
| --- | --- | --- |
| Заголовки | Noto Serif Display, `wdth` 72, вес 350 / курсив | Заголовки, крупные цифры. Плотный интерлиньяж (0,9–1,0), отрицательный трекинг. Курсивом — одно акцентное слово в заголовке. Сужение по оси ширины повторяет характер Instrument Serif из референса (у неё нет кириллицы) |
| Интерфейс / текст | Geist (variable) | Базовый 16 px, интерлиньяж 1,6, до 62 знаков в строке |
| Метки | Geist Mono | Подписи 11–12 px капсом, индексы, теги, код. `tracking-[0.14em]` |

Плавная шкала (`clamp`, без скачков на брейкпоинтах): `display-xl` 48→148 px, `display-l` 44→104 px,
`display-m` 32→60 px, `display-s` 24→36 px, `body-l` 18→20 px.

Русская типографика: неразрывные пробелы после коротких слов и перед тире, «ёлочки», мягкие
переносы в очень длинных словах крупного кегля (`npm run typograf`).

## Отступы и сетка

- Базовая единица 4 px. Ритм секций: `py-[clamp(6rem,12vw,11rem)]`.
- Контейнер: максимум 1440 px, поля `clamp(1.25rem, 4vw, 3rem)` (`.container-x`).
- Сетка: 12 колонок от 1024 px, 6 колонок от 768 px, 4 колонки ниже. Межколонник 24 px на десктопе, 16 px на мобильных.
- Редакционные раскладки намеренно ломают симметрию (смещённые колонки, моменты во всю ширину).

## Форма, глубина, стекло

- Медиа и редакционные блоки: острые углы (0–2 px). Элементы управления: «таблетка» (`rounded-full`). Панели: 24 px.
- Никаких теней у контента. Глубину даёт свет: внутренний блик `inset 0 1px 1px rgb(255 255 255 / .1)` и градиентная рамка.
- `.liquid-glass` — почти прозрачная заливка, блюр 4 px, luminosity-смешивание, градиентная рамка через маску.
- `.liquid-glass-strong` — та же рамка, плотнее заливка и блюр 20 px — для навигации при скролле и оверлеев.

## Моушн

| Токен | Значение | Применение |
| --- | --- | --- |
| `ease-out-expo` | `cubic-bezier(.16,1,.3,1)` | Появления, раскрытия |
| `ease-in-out-quart` | `cubic-bezier(.76,0,.24,1)` | Оверлеи, шторки |
| Микро | 150–200 мс | Цвет и прозрачность при наведении |
| Трансформации при наведении | 300–450 мс | Кнопки, строки, масштаб медиа |
| Появление | 700–1000 мс, шаг 60–80 мс | Строки текста, раскрытие медиа |

Только transform/opacity. Бесконечно повторяется только ролик первого экрана.

Реализация: появление секций — на CSS (`[data-reveal]`, `[data-reveal-text]` в globals.css),
класс переключает один общий `IntersectionObserver` (`components/ui/reveal-observer.tsx`).
Анимации по скроллу и появление/исчезновение — на ленивых компонентах `m` из Motion; движок
грузится после гидрации.

`prefers-reduced-motion` выключает плавный скролл, кастомный курсор, 3D по скроллу и
трансформации появления — каждая секция сразу видна в финальном читаемом состоянии.

## Состояния взаимодействия

| Состояние | Решение |
| --- | --- |
| Наведение | Текст `fg-muted → fg`, стекло `+white/5`, медиа `scale 1.03`, магнитное притяжение у главных CTA |
| Фокус с клавиатуры | Контур 2 px цвета акцента, отступ 3 px — никогда не убирается |
| Нажатие | `scale(.97)` |
| Недоступно | Прозрачность 40 %, без событий указателя |
| Загрузка | Спиннер + глагол («Отправляем…»), `aria-busy` |
| Ошибка | Текст ошибки под полем, `aria-invalid`, фокус переходит на первое неверное поле |

## Брейкпоинты

Стандартные Tailwind: `sm 640`, `md 768`, `lg 1024`, `xl 1280`, `2xl 1536`.
Полное меню — от 1024 px (русские пункты длиннее), ниже — бургер с полноэкранным меню.
Проверено на 375, 768, 1024 и 1440 px. На тач-устройствах — системный курсор, облегчённое 3D
и никакого перехвата скролла.
